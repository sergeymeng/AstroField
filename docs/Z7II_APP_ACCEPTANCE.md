# Z7 II App 内验收清单

适用设备为通过 USB 连接的 Nikon Z7 II。下表列出室内测试结果，取景拉伸、找星和自动重连按第 2.1 和第 7 节复测。

## 前置条件

- 相机 USB 模式设为 MTP/PTP。退出 Photos、Image Capture、Nikon Transfer 等可能占用相机的程序。
- 使用支持数据传输的 USB-C 线。机身电量高于 30%，存储卡可写。
- App 与 CLI 不要同时操作同一台机身。
- 每一步记录：时间、机身固件、镜头、操作、结果、错误文本。失败时停止该步，拔出 USB，重启 App 后重试。

在仓库根目录运行设备诊断。

```bash
./run.sh icc --seconds 3
./run.sh iccprops
```

预期：列出相机；属性读取无超时。无相机时输出 `no ICC camera found`，与 App 的连接错误路径一致。

## 1. App 内 Nikon 连接

操作：

1. 启动 `./run-app.sh` 或 `open dist/AstroField.app`。默认为模拟相机。
2. 顶部来源菜单选择 Nikon USB。

预期：10 秒内状态栏显示机身型号（如 `Z 7II`），能力标记出现 `LV RAW MF`，日志显示「已连接 …（Nikon USB）」。连接后自动进入 LIVE 取景。

记录：连接耗时、机身型号、能力标记、电池百分比（如有）。

失败对照：15 秒超时并显示 `no ICC camera found`。依次检查 USB 模式、占用程序、线材、机身在开机状态。

## 2. LiveView

操作：

1. 保持 LIVE 模式 30 分钟，观察是否断流。
2. 切换到最后一张再切回 LIVE。
3. 打开 VIEWFINDER 面板，开启取景辅助，依次切换 2×、4×。

预期：中央监看持续刷新；左上显示 LIVE、来源、帧号；右上显示 ISO / SHUTTER / IRIS。取景辅助只在 LIVE 生效，不改变照片与测量输入。

记录：取景分辨率、帧率、30 分钟内掉线次数、2×/4× 中心裁切是否正常。

底层等价命令：

```bash
./run.sh icclv --seconds 10 --out logs/lv
```

## 2.1 LiveView 拉伸与找星模式

前置：相机已连接，镜头对准夜空或有星点的远处。暗环境下 LiveView 原始 JPEG 可能只有噪声。

取景拉伸：

1. VIEWFINDER 面板确认「取景拉伸」开启（默认开启）。
2. 增益从 1.0× 调到 2–3×，黑场保持在 −0.2σ 左右。
3. 观察星点是否出现；面板显示「背景 中位 / σ」。
4. 关闭「取景拉伸」，画面应回到未拉伸的原始 LiveView。
5. 测试后打开取景辅助，确认 FWHM 与星点数量不因拉伸开关而变化（测量使用原始帧）。

预期：星点在拉伸后可见；分析和对焦输入不受拉伸影响；1024×680 下取景刷新不低于 10 fps。
单帧拉伸耗时可用 `swift test -c release --filter LiveViewStretchTests` 检查。

找星模式：

1. 在 VIEWFINDER 面板点「找星模式」。状态栏与监看左上应显示 FIND，ISO 临时变为 12800。
2. 观察画面星点标记；最亮星应有十字与外圈标记，面板显示峰值与 FWHM。
3. 记录 LiveView 星点数；如果连续 3 个分析帧为 0 颗星，App 会自动拍一张
   2 s / ISO 12800 / JPEG 测试帧，下载后拉伸、检测并显示。测试帧不写入会话目录、
   不进素材区、不进序列。
4. 盖住镜头盖再进入找星模式：应显示「未检测到星点」或「测试帧：未检测到星点」，
   不得显示找到星点。
5. 目标为星点时，点「对焦最亮星」。有 MFDrive 时镜头应沿单星窗口搜索，结束后显示
   「已对焦 FWHM x.xx」或「未确认」。
6. 点「退出找星」，确认 ISO 与拍摄参数恢复为进入前的值，LiveView 恢复。

记录：进入/退出耗时、临时 ISO 是否写入成功（0x500F）、LiveView 星点数、测试帧耗时与
落盘位置（应为临时目录且已删除）、最亮星 FWHM、MFDrive 方向与步数、退出后参数回读。

底层辅助诊断（不要与 App 同时操作相机）：

```bash
./run.sh iccprops
```

关注 `0x500F ExposureIndex` 是否在进入/退出后往返。

## 3. 1 秒 RAW 单张与下载

操作：

1. 参数区设置 ISO 800、SHUTTER 1s、IRIS f/2.8。
2. 按 ⌘↩ 或点击试拍一张。

预期：状态进入曝光，随后素材区出现 `DSC_xxxx.NEF`。分析面板显示尺寸与指标（室内无星时显示「星点不足，无法判断清晰度」）。文件落在 `~/Pictures/AstroField`。

记录：文件名、大小、曝光到落盘耗时、下载速率。历史实测：81.5 MB @ 23.7 MB/s。

底层等价命令：

```bash
./run.sh iccshoot --out logs/cap --remote --exposure 1
```

通过标准：文件可用来源菜单的照片回放打开，裁切与指标可显示。

## 4. 自动对焦

操作：

1. 镜头 AF 开关打开，机身对焦模式确认。
2. 取景画面内至少 3 个可测目标（室内可用远处点光源）。
3. FOCUS 面板点击自动对焦。

预期：曲线逐点出现，结束后显示「已确认」或「尚未确认」，并给出 FWHM 前后值；随后按拍摄参数补拍一张验证帧并进入分析。证据不足时不得显示成功。

记录：方向 1/2 的实际物理效果、空行程、步幅、起始与结束 FWHM、搜索步数、确认状态。

底层等价命令：

```bash
./run.sh iccfocus --direction 1 --steps 100
```

注意：方向 1/2 的物理含义随机身与镜头组合变化，不要跨镜头外推。

## 5. 关屏

App 内入口：Nikon 连接后，FOCUS 面板底部出现「关闭相机屏」开关。打开时先把相机切到
PC mode 并发送 ChangeMonitorOff，关闭时恢复屏幕并切回 remote mode。

操作：

1. 在 FOCUS 面板打开「关闭相机屏」。
2. 观察机身屏；再关闭开关恢复。
3. 关屏状态下试拍一张，确认是否仍能拍摄。

预期：日志显示「已请求关闭相机屏」，`MonitorOffStatus` 回读 1。若失败，界面显示错误文本。

CLI 备用路径（与 App 不要同时操作相机）：

```bash
./run.sh iccmode pc
./run.sh iccmonitor off
```

恢复：

```bash
./run.sh iccmonitor on
./run.sh iccmode remote
```

记录：`monitor_off_status` 值、屏幕实际状态、关屏后执行 `iccshoot` 是否仍成功、App 内
LiveView 与试拍是否仍可用。

判定：如果关屏与 App 拍摄流程兼容，保持 App 内开关；不兼容则记录原因并只保留 CLI 诊断。

## 6. 3 张短序列

操作：

1. PLAN 设为 1 秒曝光、ISO 800、曝光后等待 2 秒、结束张数 3。
2. 空格开始。中途测试暂停/继续一次。

预期：3 张 NEF；已曝光、已保存、失败计数分别正确；倒计时与下一张时间更新；日志无错误。

会话检查：

- 每次开始序列会建立带时间戳的会话目录，路径显示在 SESSION 面板。
- 真实 NEF 只记录 sidecar，不复制、不修改原文件。
- SESSION 面板可以导出 CSV/JSON 报告。

记录：会话目录路径、sidecar 数量、报告能否打开、NEF 的原始路径是否与 sidecar 一致。

## 6.1 真实机身暗场

操作：

1. 盖住镜头盖或装机身盖，保持与正式拍摄相同的 ISO 与曝光。
2. DARK 面板把帧数设为 4，点击采集暗场。
3. 采集完成后检查库条目：ISO、曝光、4 帧、均值、热像素数。
4. 打开镜头盖，用相同参数试拍一张，查看分析面板「已减暗场」与背景变化。

记录：每帧下载耗时与文件大小（真实机身每帧会下载一个 NEF 到 `~/Pictures/AstroField` 根目录）、
master 均值、热像素数、减暗前后背景与噪声、是否有异常热像素残留。

注意：暗场帧数与温度都会影响效果；不同温度、不同曝光档位应分别采集。

## 7. 断线恢复与自动重连

场景 A：USB 拔出/插回。

操作：

1. LiveView 运行中拔掉 USB。
2. 状态栏不得继续显示「已连接」；应显示「重连中 n/5」，监看保留最后一帧并显示重连层。
3. 10 秒内插回 USB。
4. 观察状态栏变为「已恢复」，随后回到「已连接」；LiveView 自动恢复。
5. 恢复后立即单张试拍一张，确认拍摄可用。

预期：重连由 App 自动完成，不需要重新选来源；最多重试 5 次（1 s / 2 s / 5 s / 5 s / 5 s），
失败后停止重试并显示明确错误。日志中只出现一条「ICC 会话断开」和最多 5 条重连失败。

场景 B：相机休眠或 ICC 会话被机身关闭。

1. 保持 LiveView，等待机身待机计时（或按机身设置触发）。
2. 复现后检查日志：应出现 `ICC 会话断开：session closed...` 或 `device removed`。
3. 若属于「session closed」且相机仍在 USB 上，自动重连应成功；若相机休眠到 USB 级，
   需要手动唤醒机身。

场景 C：显示器休眠与唤醒。

1. 保持 Nikon 连接，打开 VIEWFINDER 的「保持后台活跃」（默认开启）。
2. 让显示器休眠 1–2 分钟，再唤醒；LiveView 应继续刷新或自动重连。
3. 检查日志是否记录「显示休眠 / 显示唤醒」，与 ICC 断开时间对照。

场景 D：序列拍摄期间断线。

1. 启动短序列，在两次曝光之间拔掉 USB，检查序列是否暂停。
2. 插回 USB，等状态栏显示「已恢复」，确认序列仍处于暂停状态。手动继续并检查下一帧是否保存。

记录：断开原因文本（`session closed` / `device removed` / `notConnected`）、显示与系统休眠
时间（App 日志 + `pmset -g log`）、重连尝试次数与耗时、恢复后 LiveView 与单张是否正常。


## 机身与镜头设置

- 关屏只在 PC mode 下设置；App 拍摄会切回 remote mode，屏幕可能自动点亮。以实测为准。
- 自动对焦优先使用 LiveView 测量，结束后补拍验证帧。真实镜头的空行程与步幅尚未标定。
